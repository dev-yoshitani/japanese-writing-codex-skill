# Application

奨学金、志望理由、自己PR、留学、インターン、コンテスト応募に使う。

## 事実境界

経験、役割、実績、受賞、研究、行動、結果、数値、健康情報を推測または誇張しない。本人が確認していない内容は `要本人確認` とする。将来の希望を実績のように書かない。

## 構成

必要に応じて、経験、課題、行動、結果、得たもの、今後を使う。資料にない要素を埋めるために架空の出来事を追加しない。経験が不足する場合は、確認質問または空欄ラベルを使う。

## 内容

- 募集目的と設問へ直接答える。
- 「成長した」「貢献したい」だけで終えず、根拠となる行動や接続を示す。
- 美辞麗句で実績を大きく見せない。
- 組織名、制度名、年度、金額、応募条件を正確に保つ。
- 個人情報と健康情報は、ユーザーが提供し使用を許可した範囲を越えない。
- 文字数上限がある場合は余裕を持たせ、最終稿で数え直す。実countと採用した数え方は本文外に一行で示す。

既存の本人らしい表現は、設問適合性を損なわない限り残す。
