# 定型的な日本語を構成から直す

これは編集上の経験則であり、検出器の学習特徴や非検出率を示すものではない。
目的・事実・本人の言い方を固定してから使う。全項目を毎回文章へ当てはめない。

## 原文の型から一度離れる

構成の変更が許可されているときは、完成稿をすぐ言い換えず、段落ごとに「伝える内容」「根拠」「重複」を短く整理する。
本人メモがあれば、実際の判断と作業を先に拾う。本人の経験を推測して材料を増やさない。
原文の具体的で本人らしい表現は残す。構成は設問に応じて選び、全段落へ同じ型を繰り返さない。

| 読者が知りたいこと | 情報の置き方 |
| --- | --- |
| 活動費を何に使うか | 使途を先にし、その費用が要る活動を続ける |
| どのように判断したか | 実際の条件から入り、判断と理由を続ける |
| 実験から何が言えるか | 観察・数値から、言える範囲と未確認点へ進む |
| 経験からどう考えたか | 実際の出来事から、本人が述べた認識の変化へつなぐ |

並列の論点に、原文にない優先順位や因果関係を付けない。

## 症状と修正理由を対応させる

| 症状 | 確かめること | 根拠がある場合の直し方 |
| --- | --- | --- |
| 「単なるAではなくB」 | Aの否定は読者の誤解を直すか、実質的な区別か | 強調だけならBを直接述べる。真正な対比は残す |
| 「重要な点があります」などの予告 | 後に具体的内容があるか | 内容を先に述べる。重要度自体が主張なら保つ |
| 具体例の直後に同じ教訓を再掲 | 結びに新しい判断・条件があるか | 重なる部分を削り、その例で終えてもよい |
| どの段落も結論・三例・総括 | 段落の役割は本当に同じか | 背景を短くし、判断に必要な箇所を厚くする |
| 名詞が連なり動作が不明 | 誰の行為かが原文から分かるか | 既知の主体と動詞を対応させる。専門用語は保持する |
| 接続詞で文を接着 | 何を受け、どの関係を示すか | 前文の対象を次文で受ける。未知の因果は作らない |
| 抽象的な評価が連続 | 根拠となる作業・観察が材料にあるか | 既存の具体情報を中心にする。なければ無理に具体化しない |
| 同義語を次々に使う | 同じ物を別の物のように見せていないか | 対象名を統一する。専門語を装飾目的で置換しない |
| どの文にも推量表現 | 原文でどこまで分かっているか | 観測・推定・未確認を保ち、重ねた留保だけを整理する |
| 「〜ことができました」を一律短縮 | 能力・達成への評価が含まれるか | 単なる完了だけと確認できる場合に限って縮める |
| 敬語が重なり主体が不明 | 書き手と読み手の関係は何か | 誰が何をするかを保って自然な敬語にする |
| 同じ敬体の語尾が続く | 実際に読みづらいか | 語順や文のまとまりを直す。敬体と常体を演出で混ぜない |
| 見出し・太字が細かすぎる | 内容の区別に役立つか | 役割のない装飾を減らす。手順や比較の一覧は残す |
| 読者が知る背景を再説明 | 今回の用件に必要か | 既知情報を短くして用件へ進む |
| 「今後に生かしたい」で毎回閉じる | 本人がその意向を述べたか | 未提示なら足さない。本人の意向なら意味を保って残す |

## 日本語の例

以下は架空の編集用例であり、ユーザーの経験へ転用しない。

- 「寸法変更後の干渉確認を実施した。」→「寸法を変更したあと、干渉を確認した。」：作業と順序を保持する。
- 「試作品を測定し、図面の寸法と比較した。この経験は寸法を確認する大切さを学ぶ経験になった。」→前文で完結させるか、後文が本人の重要な学習報告なら残す。重複に見えても文書の目的を確認する。
- 「試験で確認していないが、計算では成立する可能性がある。」→そのままでもよい。未確認の範囲と根拠の種類が伝わっている。
- 「予定どおりに作業を終えることができました。」→達成の実感を含むならそのまま残す。「終えました」へ必ず縮めない。
- 「直径は12 mm、長さは30 mmである。」→そのまま残す。数値の入替えや、単調さだけを理由とした分割はしない。

## 別の観点で読み直す

第一読は意味の確認に使う。原文の各主張がどこに残り、新しい主張の根拠が何かを確かめる。
第二読は読者の理解に使う。話題の飛躍、指示先、重複する結び、本人の語彙から離れた表現を探す。
本人の参考文があれば、難しい語を選びすぎていないか、説明を整えすぎていないかも比較する。
本人から「なんか違う」と指摘されたら、語調・内容・構成のどれが違うかを原文と照合して直す。全文を別の模範文へ再生成し続けない。

## 判定結果を使う改稿

測定できる連携があれば実際に測る。なければ完成稿を仕上げ、全文と結果が必要なことを短く伝える。
測定結果がないことを理由に、構成や文章の改善まで止めない。未計測の案に架空の点数を付けない。
比較の依頼では最大3案を、(A)よい表現を残す修正、(B)論点から再構成、(C)本人メモを中心にした構成として作れる。材料が同じなら無理に3案作らない。
設問・引用範囲・文字数条件をそろえ、内容を監査した案だけを同じ条件で測る。
指摘箇所を文脈ごと読み直し、上表のどの問題に当たるか確認する。単語が指摘されたという理由だけで同義語を回さない。
表示結果が改善し、内容と文体も維持できる場合だけ採用する。悪化したら最良の既存案へ戻す。
既定の追加修正は2回とし、徹底した改善を依頼され、実測で改善が続く場合は最大6回まで継続できる。改善停止、意味・読みやすさの悪化、利用枠の制約で終了する。
この回数は作業量の上限で、検出器の性質に関する閾値ではない。非検出だった場合も、その全文と測定条件での結果としてだけ報告する。
